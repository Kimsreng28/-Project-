### **Running the Application**

1. **Start the Server**:

   ```bash

   gradlew run  --args='server'

   ```

2. **Run the Client**:

   ```bash

   gradlew run  --args='client'

   ```

3. **Run the Test**:

   ```bash

   gradlew build test

   gradlew test

   ```

4. **Run Interface**:

   ```bash

   gradlew bootRun

   http://localhost:8081/

   ```
